# Years 6–9 review

The next development project has a [playable direct-touch preview](TOUCH-PLAYABLE.html) with seven isolated activities and an embedded coverage table. Download the raw HTML and open it locally, or run `npm run preview:touch` and visit `http://127.0.0.1:4173/dev/touch-preview.html`. The offline Test Camp also has a review link. See [the flow audit and coverage notes](../TOUCH-INTERACTIONS.md) and [test evidence](../TOUCH-VALIDATION.json). This preview is not a release or deployment; physical iPad Safari remains untested.

[YEARS6-9.html](YEARS6-9.html) is a self-contained review gallery with **66 actual running-game captures**, all nine worlds, curriculum coverage, tested viewports and remaining acceptance work. Download the raw HTML file from GitHub, save it with its `.html` extension and open it in a current desktop browser. Images and filters are embedded; no hosting or account is required.

For a local served review, run `npm run preview` from the repository and open `http://127.0.0.1:4173/docs/review/YEARS6-9.html`. The game itself remains the fictional offline Test Camp at `/v3-adventure.html`. This is separate from the live game.

See [the curriculum document](../YEARS6-9-CURRICULUM.md) for the proposed KS3 progression, [coverage and question keys](../CURRICULUM-COVERAGE.json), and [validated checks](../CURRICULUM-VALIDATION.json). The gallery is a review artifact; physical iPad Safari and learner-paced timing acceptance are still pending.
