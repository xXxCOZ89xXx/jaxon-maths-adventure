# One map per area — before and after

Before: exact release 914724a6, offline fictional fixture. After: private-build fictional fixtures with the same area progress. Both builds use the shared scene code. Screenshots show the desktop overview; CI evidence includes all four sizes in private and demo builds.

The normal maps and mission entrances remain. The main-screen repair overlays/duplicate Town repair map are replaced by a labelled repair panel. The full stage list opens from its keyboard-accessible summary.
