## Boundaries and portability

Static WebP assets and ordinary DOM/native dialogs work with the existing static build on Cloudflare Pages or Vercel. No provider-specific runtime was added. Original PNG masters remain in the workspace; the runtime manifest records dimensions, alpha, byte sizes and digests. Layer atlases are purpose-made game assets, not crops of the approved reference boards. The 34 new assets total about 11 MiB; each screen loads its relevant assets, while the optional standalone offline preview embeds the full set.

This remains a 2.5D game with fixed scene cameras, calibrated character anchors, sprite layers and interactive close-ups. It is not a free-walking/collision-based 3D simulation. The four exterior appearances group the eight logical levels; they are not eight separate paintings. Character items have fixed front-facing poses rather than skeletal cloth animation. Restoration currently clears three repair sites, rather than repainting the entire background. These are explicit implementation limits, not unimplemented educational routes.

No Auth/PIN, Supabase, cloud adapter, wallet/reward rules, storage namespace, existing Town-plan generator or historical evidence reset was changed. No accounts or real progress were used in testing. The live release and hosting remain untouched.
